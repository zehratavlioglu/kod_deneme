# Güvenlik politikası

RideLink henüz MVP/PoC aşamasındadır ve üretim güvenlik garantisi sunmaz.

## Güvenlik açığı bildirimi

Depo özel olduğu için güvenlik bulgularını herkese açık issue veya commit içinde paylaşmayın. Depo sahibine GitHub üzerinden özel olarak iletin ve aşağıdaki bilgileri ekleyin:

- Etkilenen commit veya sürüm
- Tekrarlama adımları
- Olası etki
- Varsa önerilen düzeltme

Ham mikrofon sesi, Nearby doğrulama bilgileri, gerçek cihaz kimlikleri, imzalama anahtarları veya kullanıcıya ait başka hassas verileri rapora eklemeyin.

## Kapsam

Özellikle otomatik ilk eşleşme, Nearby kimlik doğrulaması, binary paket ayrıştırma, Android izinleri, foreground-service yaşam döngüsü ve Bluetooth ses yönlendirmesi güvenlik açısından hassas alanlardır.
